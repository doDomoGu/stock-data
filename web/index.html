我的自选

大盘看什么（和个股有什么不同）

没有财报可看：指数是成分股的加权结果，单家公司的营收利润不直接决定指数走势，所以大盘分析不看 ROE、毛利率这些。

趋势：均线排列与年线位置最重要。指数站上/跌破 20、60、250 日线，代表不同周期的资金成本。

量能：上涨是否放量、下跌是否缩量，比单只股票的成交量更有意义——它反映的是全市场资金态度。

宽度：涨停与跌停家数反映赚钱效应。指数涨但只有少数权重股在涨，说明参与度差。

估值：指数也有 PE/PB 分位（如沪深300），但需要专门的指数估值数据源，当前版本未接入。

推荐指数 = 位置与年线 30% + 估值 25% + 财务 25% + 动能 10% + 相对强度 10%。 它是按固定规则算出的相对评分，不是上涨概率，也不预测短期涨跌。

怎么看这些数字

推荐指数：把五个维度加权成一个 0~100 的相对分数。高分只说明"按这套标准现在的条件较好"，不代表会涨多少、什么时候涨。

年线（MA250）：过去 250 个交易日的平均成本，常被当作一年的"价值中枢"。价格低于年线说明多数持仓者浮亏；"乖离率"是现价偏离年线的百分比，负得越多说明离中枢越远。

分位：把当前值放进这只股票自己的历史里排序。比如"年线乖离 0.2% 分位"意思是过去几年只有 0.2% 的时间比现在更便宜——这是相对它自己，不是和别的股票比。

PE / PB：市盈率（股价 / 每股收益）与市净率（股价 / 每股净资产）。看绝对值意义有限，看历史分位更能说明贵不贵。

动能：短期资金与趋势的状态（均线排列、MACD、RSI）。动能弱而估值低，往往是"便宜但还在跌"，需要耐心。

怎么用：先用指数筛出候选，再点开看五维拆解和风险提示，最后结合公告与行业判断。指数只负责把注意力放到值得看的地方。
